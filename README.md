# FORM — Gym Planner

A static, GitHub Pages-ready personal training dashboard for strength, running, progression, and workout logging.

## Features

- Monday / Friday full-body strength plan
- Wednesday / Sunday running plan
- Planned targets and actual workout logging
- Persistent browser storage (no backend required)
- Dashboard statistics, streaks, volume, running distance
- Animated strength progress chart with target trajectory
- Progressive-overload recommendations
- Editable 12-week goals
- Workout history
- Export / import of all training data
- Responsive desktop and mobile UI

## GitHub Pages

This project is intentionally plain HTML/CSS/JavaScript and can be served directly from the repository.

In GitHub:

1. Open **Settings**
2. Open **Pages**
3. Under **Build and deployment**, choose **Deploy from a branch**
4. Select **main** and **/(root)**
5. Save

The app stores training data in `localStorage` in the current browser. Use **Settings → Export data** if you want a backup or want to move the data to another browser/device.
